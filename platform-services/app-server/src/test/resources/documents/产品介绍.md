# 智云助手 产品介绍

智云助手是智云科技面向企业推出的 **智能知识中台**，基于检索增强生成（RAG）架构构建。

## 核心特性

- **多格式接入**：支持 PDF、Word、Markdown、HTML、CSV、JSON 等 12 类文档格式
- **混合检索**：稠密向量检索 + BM25 关键词检索，召回率显著高于单一方案
- **权限隔离**：按部门与文档密级控制检索范围
- **可溯源**：每次回答均标注来源文档与置信度

## 快速开始

```bash
# 安装 CLI
pip install zhiyun-cli

# 初始化知识库
zhiyun init --workspace ./kb

# 导入文档
zhiyun ingest ./docs --recursive
```

## 典型场景

1. 新员工入职问答（HR 政策、报销流程）
2. 售后知识检索（产品手册、故障排查）
3. 内部研报摘要（长文档要点提炼）

> 提示：导入前请确保文档已去除水印与加密，否则解析可能失败。
