# RAG 知识库验证样例集（智云科技）

本目录是一套围绕同一虚构主体「智云科技」的多格式示例文档，专为 RAG 系统的 **解析 -> 切片 -> 向量化 -> 检索 -> 生成** 全链路技术验证而准备。

> 设计意图：不同格式中埋入了 **相互关联甚至重复**的知识点（如「支持的文档格式」、
> 「年假政策」「密码重置」），便于验证跨格式召回与答案溯源能力。

## 1. 文件清单

| 格式     | 路径                   | 内容                   | 解析验证重点               |
|----------|------------------------|------------------------|----------------------------|
| Markdown | `md/产品介绍.md`       | 产品特性、代码块、引用 | 标题层级、列表、代码块保留 |
| 纯文本   | `txt/公司简介.txt`     | 公司概况               | 无结构文本分段             |
| HTML     | `html/帮助中心.html`   | FAQ、超链接            | 标签清洗、正文抽取、去导航 |
| CSV      | `csv/员工信息.csv`     | 员工结构化数据         | 表格->文本、字段对齐       |
| JSON     | `json/配置数据.json`   | 检索/切片配置          | 结构化字段抽取与扁平化     |
| Word     | `docx/员工手册.docx`   | 多级标题+表格          | 富文本、表格提取、样式     |
| PDF      | `pdf/技术白皮书.pdf`   | 多页白皮书             | 分页、版面、列表           |
| PPTX     | `pptx/产品发布会.pptx` | 发布会幻灯片           | 每页文本、要点提取         |

## 2. 建议的检索测试问题（可直接喂给 RAG）

**A. 跨格式事实类（验证召回与溯源）**

1. 智云助手支持哪些文档格式？
2. 员工年假最少和最多能休多少天？
3. 忘记密码后如何重置？

**B. 聚合/推理类（验证多片段融合）**

4. 智云科技的检索方案用了哪几种技术？
5. 公司在安全合规上做了哪些措施？
6. 研发部有哪些员工，分别在哪座城市？

**C. 结构化数据类（验证表格/JSON 解析）**

7. 2020 年之前入职的员工有哪些？
8. 检索层的重排序（rerank）模型是什么？

## 3. 验证 checklist 建议

- [ ] 每种格式都能被成功解析为纯文本，且不丢关键内容
- [ ] 表格（docx/csv）的行列关系在切片后仍然正确
- [ ] 同一问题能从多个格式召回相关信息
- [ ] 生成答案能正确引用来源文件名
- [ ] 切片大小/重叠参数与 `json/配置数据.json` 中声明一致
