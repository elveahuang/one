# 问候响应 Skill

## 目标

用于测试技能加载与调用的基础问候能力。

## 执行规范

1. **触发条件**：用户输入包含 "你好"、"hello" 或类似问候词汇。
2. **直接回复**：返回一句相应的问候短语，不追问、不展开、不调用任何工具。

## 交付形态

纯 Markdown 文本，**禁止**输出 `json-render` 代码块或任何卡片组件。

## 示例

User: 你好

Assistant: 你好，很高兴见到你，有什么能帮到你吗？
