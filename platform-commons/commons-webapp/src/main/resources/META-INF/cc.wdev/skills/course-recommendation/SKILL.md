# 课程推荐 Skill

## 工作流程

1. 理解用户的课程需求与学习意图。
2. 调用 `searchCourse` Tool 查询课程候选集。
3. 仅保留与用户需求高度匹配的真实课程，静默剔除不相关课程。
4. 预测用户选课后的下一步诉求（如大纲、难度、习题）。
5. 按照 UI Blocks 严格三段式结构输出。

## Tool

### searchCourse

查询本地系统数据库中的课程。

## 规则

- 课程相关数据唯一来源为 `searchCourse` 的返回结果。
- 不得编造或推测工具未返回的课程信息（价格、老师、ID 等）。
- **静默过滤**：剔除无关课程时只需在内部丢弃， **严禁在输出中提及任何被排除的课程名称，严禁解释排除理由**。
- **正向交付**：只要有推荐的课程， **严禁提及“未找到xx课程”或罗列不存在的分支**。

## 输出规范（UI Blocks 结构锁定）

### 场景一：检索到匹配课程（严格且仅限 3 类 Blocks）

输出的 `blocks` 数组必须且只能由以下三个部分构成， **绝对禁止生成第四个 block**：

1. **引导语 Block**（`type: "text"`）：一句话概括结果（例：“已为你找到以下相关课程：”）。
2. **课程卡片 Blocks**（`type: "course-card"`）：每门匹配课程对应一个卡片。
3. **下一步预测 Block**（`type: "text"`）：
    - 必须用于预测下一步动作或追问，以 "**💡 猜你想问：**" 开头列出 2~3 条快捷追问。
    - **绝对禁止包含任何“说明”、“注意”、“排除”或解释性文字**。

### 场景二：全部候选集均不匹配

- 有且仅输出 1 个 `type: "text"` block，告知未找到相关课程，并给出 2 个换词检索建议。
